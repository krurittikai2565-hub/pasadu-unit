# ระบบพัสดุหน่วยเบิก

ระบบควบคุมพัสดุระดับหน่วยเบิก (แผนกวิชา / งาน) ตามคู่มือระบบการควบคุมพัสดุของกรมอาชีวศึกษา
หน้าเว็บอยู่บน GitHub Pages ข้อมูลเก็บใน Google Sheet ของแต่ละหน่วยเบิก

- ใบเบิก / ใบส่งคืน แบบ พ.3101 (ออก PDF ลงแบบฟอร์มจริง), ทะเบียนใบเบิก พ.3105
- บัญชีคุมวัสดุ พ.3104, บัญชีคุมครุภัณฑ์ พ.3103, ใบเบิกภายใน พ.3101-1, ประวัติครุภัณฑ์ พ.3109
- รายงานประจำเดือน, ครุภัณฑ์ตามห้อง, ครุภัณฑ์ชำรุด, พัสดุคงเหลือสิ้นปีงบ + ตรวจนับ
- ทุกเอกสาร: พิมพ์ / ดาวน์โหลด PDF / ส่งออก Excel

## โครงสร้าง
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บ (GitHub Pages) เรียกข้อมูลจาก Apps Script ผ่าน API |
| `apps-script/Code.gs` | โค้ดฝั่ง Google Sheet (วางใน Apps Script ของชีต) |
| `apps-script/Index.html` | หน้าเว็บสำรองที่เปิดผ่านลิงก์ Apps Script โดยตรง |

## ติดตั้งสำหรับหน่วยเบิกใหม่
1. สร้าง Google Sheet ใหม่ > ส่วนขยาย > Apps Script
2. วาง `apps-script/Code.gs` แทนโค้ดเดิม และเพิ่มไฟล์ HTML ชื่อ `Index` วางเนื้อหา `apps-script/Index.html`
3. แก้บรรทัด `const API_KEY = '...'` ใน Code.gs เป็นรหัสผ่านของหน่วย (อย่างน้อย 8 ตัวอักษร) **อย่าใส่รหัสนี้ใน GitHub**
4. Deploy > New deployment > Web app
   - Execute as: **Me**
   - Who has access: **Anyone** (จำเป็นเพื่อให้หน้า GitHub Pages เรียกได้ ข้อมูลยังป้องกันด้วย API_KEY)
5. เปิดหน้าเว็บ GitHub Pages > ใส่ URL เว็บแอป (ลงท้าย `/exec`) และรหัสผ่าน > เชื่อมต่อ
   เบราว์เซอร์จะจำการเชื่อมต่อไว้ เปลี่ยนได้ที่หน้า ตั้งค่า > เปลี่ยนการเชื่อมต่อ

## อัปเดตโค้ด
- หน้าเว็บ: แก้ `index.html` แล้ว push ขึ้น branch `main`
- Apps Script: วางโค้ดใหม่ แล้ว Deploy > Manage deployments > แก้ไข > New version (URL เดิมใช้ต่อได้)

ข้อมูลทุกอย่างอยู่ใน Google Sheet ของหน่วยเบิก (แผ่นงาน วัสดุ / ครุภัณฑ์ / ใบเบิก-ใบส่งคืน / ใบเบิกภายใน / ประวัติซ่อม / ปรับสภาพ / ตรวจนับ / ตั้งค่า) — ห้ามแก้คอลัมน์ "ข้อมูล (ห้ามแก้)" ในชีตโดยตรง
